# Teleport Cam

> 🧪 **Just a playground.** A for-fun weekend experiment, not a polished or supported product. Expect rough edges.

Make a V sign at your webcam and teleport out of your Zoom call. Make it again to beam back in. ✌️

Works on Mac with Zoom, Teams, Slack huddles, Google Meet: anything that lets you pick a camera.
Everything runs on your Mac; nothing is recorded or uploaded.

## Quick start

**1. One-time setup**: install OBS, which provides the virtual camera:

```sh
brew install --cask obs
```

Open OBS → **Start Virtual Camera** → approve it in *System Settings → General → Login Items & Extensions → Camera Extensions* → **Stop Virtual Camera** → quit OBS. You never need to open OBS again.

**2. Run it:**

```sh
./run.sh
```

Step out of frame for a few seconds while it captures the empty background, then step back in.

**3. Teleport:**
- ✌️ **V sign**: vanish. Do it again to come back.
- Or click the preview window and press `V` / `R`.

**4. Use it in a call:** in Zoom (*Settings → Video → Camera*), Teams (*Settings → Devices → Camera*) or Slack (the camera arrow in a huddle), pick **OBS Virtual Camera**, *not* your MacBook camera. Turn off the app's own background blur.

Keep Teleport Cam running while you're in the call. You can minimize the preview window; quit with `Q`.

## More details

### Effects

| Key | Effect |
|-----|--------|
| `1` | **Teleport beam** (default): a column of light, then you dematerialize, with a teleport sound |
| `2` | **Dissolve**: you burn away in glowing patches |
| `3` | **Particles**: you blow away like dust in the wind |

### Keys

Click the preview window first.

`V` vanish · `R` reappear · `B` recapture background · `S` sound on/off · `H` status bar · `M` lighting match on/off · `D` debug snapshot · `F` fullscreen · `Q` quit

You can also reappear by holding up an open palm for about a second.

### Options

```sh
./run.sh --effect particles   # start with another effect
./run.sh --camera 1           # use another webcam (see --list-cameras)
./run.sh --no-sound           # silent
./run.sh --volume 0.5         # quieter
./run.sh --no-vcam            # preview only
```

### Sounds

Each effect plays a sound, generated by code. To use your own, drop a file at `sounds/<effect>-vanish.mp3` (and optionally `-appear.mp3`), e.g. `sounds/beam-vanish.mp3`.

💡 Want that classic anime instant-teleport *zip* (yes, the Goku one)? Find a clip you like, save it as `sounds/beam-vanish.mp3` and `sounds/beam-appear.mp3`, and the beam effect will use it. No clip is included here because it's copyrighted; the `sounds/` folder is git-ignored so yours stays local.

Sounds play through your speakers, so people in the call probably won't hear them.

### Troubleshooting

- **A ghost or outline of you stays behind:** press `B` to recapture the background and make sure you're fully out of frame. Still there? Press `D` while vanished; it saves what the app sees to `debug/`.
- **Zoom doesn't list OBS Virtual Camera:** finish the one-time OBS setup above, then restart Zoom.
- **"Could not read from camera":** allow your terminal under *System Settings → Privacy & Security → Camera*.
- **The camera moved or the room changed:** press `B`.

### How it works

Your webcam → [MediaPipe](https://ai.google.dev/edge/mediapipe) finds you (person cutout) and your hands (gestures) → effects blend you into the captured empty background → [pyvirtualcam](https://github.com/letmaik/pyvirtualcam) sends the result to OBS's virtual camera → your meeting app.

Code is in `teleport_cam/`: `app.py` (main loop), `effects.py`, `gestures.py`, `vision.py` (cutout + background), `sound.py`, `overlay.py` (preview text).

Inspired by [vanish_webcam](https://github.com/Nicovic17/vanish_webcam).
